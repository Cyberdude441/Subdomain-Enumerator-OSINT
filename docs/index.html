Subdomain Enumerator (OSINT Tool)

This tool discovers subdomains of a target domain using OSINT techniques such as Certificate Transparency logs and DNS enumeration.

Features

  • Certificate Transparency log enumeration
  • DNS brute-force subdomain discovery
  • HTTP/HTTPS service detection
  • Multithreaded scanning
  • Terminal-style output interface

Installation

Clone the repository: 

git clone https://github.com/Cyberdude441/Subdomain-Enumerator-OSINT.git
cd Subdomain-Enumerator-OSINT
Create virtual environment: 

python3 -m venv venv
source venv/bin/activate
Install dependencies: 

pip install -r requirements.txt

Usage

Run the tool: 

python app.py
Open browser: 

http://127.0.0.1:5000
Enter a domain such as: 

tesla.com
example.com
google.com
The tool will enumerate discovered subdomains and classify their status.

Output Classification

  • HTTP Live
  • HTTPS Live
  • DNS Resolved
  • Down / Blocked
  • No DNS
